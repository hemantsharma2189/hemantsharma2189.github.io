# Hemant Sharma Portfolio Website

A responsive single-page DevOps and Cloud Infrastructure portfolio.

## Open locally

Double-click `index.html`, or run a simple local server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy for free

### GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Open Repository Settings → Pages.
4. Choose `Deploy from a branch`, select `main` and `/root`.

### Netlify
Drag the entire folder into Netlify Drop.

### Vercel
Import the GitHub repository into Vercel and deploy with the default settings.
